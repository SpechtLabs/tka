### ⚠ BREAKING CHANGES

* the CLI binary is now `tka` instead of `ts-k8s-auth`, in the release archives (now `tka_<version>_<os>_<arch>.tar.gz`) and in the deb, rpm and Arch packages (`/usr/bin/tka`). Scripts and shell configs that call `ts-k8s-auth` must call `tka`.
